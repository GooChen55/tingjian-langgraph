知识库资料管理

支持 UTF-8 Markdown / TXT 与可提取文字的 PDF；单文件不超过 10 MB、PDF 不超过 40 页。更新失败保留已生效的旧版。扫描 PDF 请先完成 OCR。资料中的链接与脚本不会被执行。

模型供应商配置

对话模型用于助手、资料回答和运营问数；向量模型用于知识库检索，两者可以选择不同供应商。模型名称可自行修改，请选用支持工具调用和 JSON 输出的对话模型。

API Key 只发送给后端和你选择的供应商。保存时使用 Windows 账号加密，不回显密钥。原供应商及地址不变时，密钥留空即可保留。

售后审核

审核通过后可另行发起本地模拟退款；退款任务会重试并回显结果，不涉及真实资金。非本地模拟渠道的订单不支持模拟退款。
