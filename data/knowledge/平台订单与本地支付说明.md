# 平台订单与本地支付说明

资料版本：2026-10-10。本文件描述听见本地演示环境，不是实际商业售卖或支付承诺。

## 本地演示商品
本地交易演示套餐仅用于验证下单、支付回调、售后审核和退款任务，不扣款，也不解锁课程中的付费声音。页面显示的 9.90 元是本地商品目录初始演示价格；实际下单金额由 Java 从服务端商品目录读取并保存快照，客户端不能提交价格。

## 下单与取消
创建订单需要登录和明确确认。相同账号使用同一个幂等键重试会返回同一个订单；网络超时后应继续使用原幂等键查询或重试。未支付的本地订单 15 分钟过期，定时任务将其取消；已支付订单不能通过取消入口撤销，应申请售后。课程原订单不由此定时任务修改。

## 支付结果
模拟支付成功和失败都不涉及真实资金。成功回调校验签名、时间戳、交易编号和金额后，由 Java 更新订单；重复成功回调不重复写成功事件。支付失败可以在截止前重试；已取消或超时的订单不能因迟到回调恢复为已支付。

## 声音资源
订单状态和音源是否有效是两回事。课程外部示例音源目前不可访问，本地只接通两段 MP3；本地模拟购买不绕过免费试听限制。要播放课程付费声音，需要另行接入有效资源与付费授权。
