# 个人知识空间与后续云接入

本功能实现个人知识库与听书记录驱动的前两个阶段。当前使用本项目独立资源运行；对象存储、解析与向量检索均有替换接口，未宣称已经接入新的托管云知识库。

## 用户如何使用

1. 在听书端登录，从“我的 → 我的知识空间”进入，创建自己的空间。每个账号最多5个空间，每个空间最多100条笔记、书签和文件。
2. 写笔记，或在播放器点击“记笔记 / 加书签”，把声音与当前时间点带到编辑器。保存后可以跳回该声音时间点。
3. 在“我的资料”上传自己的 MD、TXT 或文字 PDF。支持更新、下载原件、删除和失败重试。单文件最大10 MB，PDF最多40页，解析正文最多6万字；扫描件仍需要后续 OCR。
4. 在“私人资料问答”检索当前空间，查看原文来源；也可以在页面内听见助手的“检索范围”选择自己的空间。
5. 在“听书回顾”查看最近14天上报的播放区间、保存位置、相关笔记与复习提示；也可在私人助手中问“查看我的听书回顾”。

私人空间默认关闭模型处理，仍能保存、解析和使用本地关键词检索。用户明确开启后，此空间的资料才会发送给当前管理台配置的向量/对话模型，用于向量索引与引用问答。**开启的是整个空间，不是单份文件。** 现有模型可能是云 API；关闭私人模型处理，不会撤回已经发送的请求或删除过去已生成的向量。

私人助手不启用联网搜索，不混用平台会话。切换知识范围会切换会话，用户仍可恢复各范围原有会话。当前私人资料问答以当前问题检索，不宣称已实现自由的跨书推理或完善的多轮指代消解。

## 数据和职责

| 数据 | 当前存储与处理 |
| --- | --- |
| 空间、笔记、书签、文件目录、期望/生效版本 | 项目专属 MySQL 的 `personal_space`、`personal_item`，由 SQL 13 初始化 |
| 用户身份 | Java 认证确定用户；FastAPI 对每个个人请求校验归属；普通用户不能因此取得公共知识库管理权限 |
| 私人原件 | 本项目 MinIO bucket 内的 `personal/{owner}/{space}/...` 不可变对象键；下载经本人认证，不公开对象 URL |
| 异步索引 | 业务记录与 `PERSONAL_CHANGED` Outbox 同事务，复用项目知识队列及三次尝试/死信机制 |
| 文本解析 | 独立 ParserPort，当前本地 UTF-8 / pypdf，不抓取文档内链接 |
| 向量 | 开启模型后写入独立 `aillisten_dev_personal_*` 集合；按模型与维度划分，检索时强制 owner + space + 当前生效版本过滤 |
| 关键词检索 | 只对本账号当前空间有效文本建立请求内索引，不加载其他用户的私人文本 |
| 播放位置 | 保留原 MongoDB `user_listen_progress`，不改变已有保存位置接口 |
| 连续播放区间 | 独立 `personal_listen_segments`，按用户/会话/序号幂等写入，按用户与时间建立索引 |
| 私人会话 | 现有 SQLite 会话追加 scope 绑定，平台与各个人空间不能混用 |

当前私人资料目录由 Python 模块维护，不是新增一套 Java 知识库微服务。Java 继续承担认证和可播放内容校验。没有为每个用户新增容器、数据库或整份公共书籍索引，也不改动虚拟机其他项目资源。

## 必须保持的隔离

- owner 从 Java 登录身份取得；请求体不接收可指定目标用户的字段。
- 空间和资料操作同时匹配 owner、space、item；同一用户的两个空间也不能混用。
- MinIO 适配器再次检查对象键前缀；原件下载不返回后端凭据。
- Milvus 在 Top-K 召回前过滤 owner、space 与允许的生效版本；结果进入模型前只能来自已授权候选，生成后再检查删除状态和版本。
- 私人内容不进入公共知识目录、公共向量集合、全局知识图谱或联网搜索。私人问答没有跨用户共享缓存。
- 模型关闭时，解析与关键词引用在项目环境中完成，不调用向量、对话或联网接口。
- local 模式不能拿本地账号 ID 读取 VM 个人空间；当前个人模块只在 VM 模式提供。

这是应用层用户隔离。虚拟机/数据库的维护者拥有基础设施权限，不能宣传为维护者也无法访问的端到端加密。

## 播放记录的含义

播放器观察正常连续播放，约8秒上报一次区间，暂停、拖动或离开时提交当前区间。拖动前结束旧区间，跳过部分不计入覆盖；网络失败保留有限待重试队列。服务端拒绝跨度过大、时长不匹配、声音与专辑不匹配及不能公开播放的内容。

服务端按用户、播放会话、序号幂等接收，并对重叠区间求并集。区间上报不修改“最后保存位置”，避免迟到的旧区间把用户的新进度覆盖回去。数据库时长为0的历史声音表示时长未知，服务端仅使用通用时间上限；客户端取得真实媒体时长后限制操作。

区间来自客户端，不是可信的学习证明、计费依据或付费授权。回顾最多处理最近14天5000条区间、展示20个声音，超出会标记截断；已有保存位置可以展示，但不会转换成“此前全部听过”。当前回顾以事实与个人笔记生成复习提示，没有文字稿时不生成章节总结，也不承诺严格避免所有剧透。

## 云接入接口与迁移

实现位置：`python/shared/personal_knowledge/providers.py`。

| 接口 | 当前适配器 | 后续云适配器必须保留 |
| --- | --- | --- |
| ObjectPort：put/get/remove | MinioObjects | 私有对象、owner/space 前缀校验、受控下载、对象键及原文一致性 |
| ParserPort：async parse | LocalParser | 文件/页数/文本限制、明确失败；云 OCR 的输出也必须保留来源 |
| VectorPort：build/search | MilvusVectors | 稳定 chunk ID、模型维度、生效版本与召回前的用户/空间过滤 |

配置名：

```dotenv
LISTENING_PERSONAL_OBJECT_BACKEND=minio
LISTENING_PERSONAL_VECTOR_BACKEND=milvus
LISTENING_PERSONAL_PARSER_BACKEND=pypdf
```

当前只实现上述三个取值。仅把配置名改成某个云产品不会安装适配器，未实现的适配器返回明确错误。云凭据将由服务端配置管理，不放浏览器、请求体、源码或公开示例中。

后续迁移顺序：实现适配器并运行隔离契约 → 停止相关写入并备份 → 按原对象键复制原件、核验哈希 → 在云端重建带归属的索引 → 切换配置并重新索引 → 用两个用户、两个空间验证检索/下载/删除/失败恢复 → 保留回退配置。当前采用整体后端切换，不支持部分对象在本地、部分对象在云端的自动混合路由。托管知识库如果不能提供等效隔离，应使用独立知识库或其他强制授权方案，不能只在答案输出时过滤。

当前删除立即使资料退出新检索并禁止下载，历史对话、旧原件和旧版本索引暂留项目存储；尚未提供物理擦除、完整版本历史浏览和自动回收。云服务正式接入前需补齐保留期与删除策略，不能宣称删除按钮等于云端所有副本已永久擦除。

实际结果见 [个人知识空间验收](个人知识空间验收.md)。测试使用专门创建的验收账号与资料，模型授权测试会产生少量现有供应商用量。私人默认关闭模型时不需要新增云账号。

本轮不包含音频转写、云 OCR、托管云知识库、私人资料分享、全书正文抓取、跨书自由总结或生产规模压测。它们可在现有身份与服务适配边界上扩展。
