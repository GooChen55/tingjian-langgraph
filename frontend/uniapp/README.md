# 听见 · 用户端

基于 UniApp、Vue 3、Pinia 与 GraceUI 的听书用户端。当前交付 H5，覆盖注册登录、内容浏览、详情与章节、音频播放、进度恢复、助手问答、订单与售后。

## 构建

在本目录执行：

```powershell
npm ci --no-audit --no-fund
npm run build:h5
```

产物位于 dist/h5，项目启动后访问 http://127.0.0.1:29183/listen/。根目录 Start.ps1 可完成依赖安装与构建；修改前端后重新构建，不能直接修改生成的 dist 文件。

业务请求统一经助手服务代理，由 Java 核验身份。播放器定时、暂停和离开时保存登录用户进度；本地示例音频支持 Range。订单页面使用明确标记的模拟交易，不涉及真实资金和付费播放授权。

## 页面内听见助手

H5 提供全局浮动入口，首页、详情、播放器、账号页的助手按钮均打开同一窗口，不切换当前路由。窗口支持全屏、返回小窗口、收起和新建对话；打开助手不会触发播放器的离开或隐藏事件。

窗口共享 Pinia 中的消息、输入草稿和会话编号，页面切换与大小切换保留当前对话。刷新后不自动恢复界面历史；退出或切换账号清空当前消息，并丢弃旧账号尚未完成的请求结果。登录信息继续使用现有账号流程，不在助手中保存密码。

输入支持 Enter 发送、Shift+Enter 换行和中文输入法组合输入；Escape 从全屏返回小窗口，再次按下收起。消息支持展开原文来源，发送失败保留输入便于重试。全屏模式限制键盘焦点在助手内，桌面与手机均可使用。

AssistantDock.vue 仅在 H5 挂载，使用原生可访问按钮与文本框，独立于 UniApp 页面的生命周期；其他平台继续使用助手页面入口。

微信小程序及 App 真机发布尚未验证；创作、直播、钱包等保留页面未纳入当前交付入口。初始化远程示例地址不能代表有效音源，其他内容需要配置实际音频。
