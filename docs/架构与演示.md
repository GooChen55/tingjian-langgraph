## 十分钟演示

1. H5 登录，搜索专辑，展示关键词、排序、筛选和搜索建议。播放标记的本地样例，保存后刷新，再让助手读取本人进度。
2. 页面内打开助手小窗，再进入全屏。问《三体》的阅读门槛，展开引用。说明引文必须与原片段匹配；没有证据时不会编造。
3. 管理台上传一份自建 MD，等待导入图完成，再提问该资料。更新、删除后核对当前版本的检索结果。扫描 PDF 会明确失败，需要后续 OCR。
4. 在模拟交易页面创建 9.90 元订单并明确确认模拟支付。助手进入售后流程，选择本人订单、补充原因、暂停与恢复，核对卡片并点击确认。自然语言“确认”不能替代确认按钮。
5. 管理员人工审核通过，再确认模拟退款。演示响应丢失后重试复用唯一渠道回执；APPROVED 只是审核通过，REFUNDED 只是本地模拟完成。
6. 管理台问“按分类统计专辑数量，取前五名”，展开字段/指标/枚举值召回、SQL、结果、口径和审计。再请求敏感字段或写入，观察拒绝。
7. 修改一条验收专辑，展示同事务 Outbox、Rabbit 确认、消费 ACK 与 ES 结果。用失败知识导入报告说明三次尝试、死信和重试入口。
8. 展示当前验收报告与隔离清单，解释为什么知识版本切换、会话归属、SQL 白名单和业务事务需要由代码保障。

演示前检查真实模型额度、六个服务与工作进程健康，避免首次建索引耗时。初始化专辑数量是示例数据规模；两个可靠本地音源、固定小样本评测与本地模拟退款各有明确边界，不推导真实用户量、通用模型准确率或高并发性能。
