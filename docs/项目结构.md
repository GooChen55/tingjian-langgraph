# 项目结构

```text
AI_tingshu_langgraph/
├── backend/java/tingshu-parent/   Java 多模块；实际运行用户、内容、订单服务
├── frontend/uniapp/              Vue / UniApp 用户端与全局助手
├── python/
│   ├── assistant/               BFF、意图分流、工具图、售后任务及管理 API
│   ├── knowledge/               导入图、混合检索图、证据核验、知识上下文
│   ├── operations/              元数据召回图、问数图、SQL 校验及检查点
│   ├── workers/                 RabbitMQ 消费、Outbox 发布与租约续期
│   └── shared/                  资源边界、模型配置、存储与发现适配器
├── web/                         管理台、助手工作台及管理脚本
├── config/customer_flows.yaml   售后槽位与有效期规则
├── infra/vm/                    仅属于本项目的 AI 容器定义
├── scripts/
│   ├── dev/                     启动、停止、诊断与统一检查
│   ├── setup/                   资源初始化、独立容器、索引及进度迁移
│   └── verify/                  实际服务、融合、隔离、交易与固定样例验收
├── tests/                       Python 单测；Java 测试位于对应模块
├── requirements/                依赖声明与锁定文件
├── sql/                         按序迁移；虚拟机初始化时映射到专属 schema
├── data/                        原有示例资料和两个本地音频
├── docs/                        架构、部署、面试、验收及来源说明
├── .runtime/                    私有配置、日志、检查点、上传派生文件与报告（不入库）
├── Start.ps1 / Stop.ps1          根目录便捷入口
└── README.md
```

所有路径按项目根目录定位。虚拟机模式的历史、索引缓存和任务状态放在 `.runtime/vm`，与 `local` 模式分开；凭据、派生文件和验收产物不放进源码目录。原始项目资料与本项目的运行资源不共用。

个人空间：`python/shared/personal_knowledge` 保存元数据、适配器、导入/检索图和播放区间处理；`python/assistant/atguigu/listening/personal.py` 提供本人认证入口；`frontend/uniapp/pages/knowledge` 为用户页面。新增表通过 `sql/13-personal-knowledge.sql` 迁移，私人目录和对象不放入 `data/knowledge`。
