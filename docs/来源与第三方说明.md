# 来源与第三方说明

本文集中记录工程基础、资料来源和第三方组件，便于维护与归属核对。产品页面和使用文档统一采用“听见”名称，不改变已有代码和资料的来源事实。

| 组成 | 来源与使用范围 |
| --- | --- |
| Java 后端、UniApp 前端 | 基于尚硅谷“谷粒随享”听书课程工程，保留 Maven 模块及前端组件；当前增加本地身份、RBAC、公开内容入口、售后事务、模拟交易与 H5 联调 |
| Python 助手 | 基于电商小二适配入口与 LangGraph 客服示例改造；补充 Task/Knowledge/Chitchat 路由、槽位收集、可恢复售后流程和 SSE。流程节点固定在代码，未复现任意 YAML 执行引擎；真实数字人延后 |
| Python 知识服务 | 借鉴掌柜智库导入与查询图，增加 MinIO/Outbox/MQ 异步导入、Milvus、Neo4j、HyDE、多路融合与证据核验；保留 SQLite 缓存与本地基础检索。未直接启动原完整应用，未实现 MinerU/OCR/图片理解 |
| Python 运营服务 | 借鉴掌柜问数关键词、字段/指标/枚举值并行召回，实际接入 ES 与 Qdrant，整合为 LangGraph 问数流程；增加只读聚合视图、AST 校验、有限修正、澄清恢复与审计。未复制原应用全部页面和业务指标 |
| 初始化数据库、本地 MP3、部分知识资料 | 来自听书课程资料；订单与账号安全资料等为当前工程新增内容。初始化数据规模不是实际运营或用户规模 |
| Grace6 / GraceUI | 前端使用的第三方组件与数据；保留原版权、授权和作者声明 |
| WeCropper 及其他依赖 | 保留源码内已有 MIT 等许可证声明；各依赖遵循其自身许可证 |
