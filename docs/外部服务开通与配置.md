# 外部服务开通与配置

维护者已决定后续准备微信支付、腾讯云点播和数字人。本轮不自动注册、购买或调用真实资金渠道。以下信息按 2026-10-15 官方文档核对；实际资格、价格与控制台以官方为准。

## 腾讯云点播

1. 注册并实名腾讯云账号，在 [云点播控制台](https://console.cloud.tencent.com/vod)开通服务。
2. 新建应用 `aillisten-dev`，避免使用其他项目的应用。保存应用 ID `SubAppId`。
3. 为本项目创建 CAM 子用户及仅用于点播所需操作的策略、API 密钥，保存 `SecretId` / `SecretKey`。
4. 上传自己有使用权的测试音频，保存返回的 `FileId`；后续根据播放鉴权方案补齐播放器签名和域名配置。

官方参考：[快速入门](https://cloud.tencent.com/document/product/266/8757)、[应用体系](https://cloud.tencent.com/document/product/266/14574)、[API 参数](https://cloud.tencent.com/document/product/266/110904)。

## 微信支付

先在 [微信支付商户平台](https://pay.weixin.qq.com/)确认符合条件的经营主体与经营场景。普通商户网站接入通常需要营业执照、身份与结算账户等材料，个人收款码不能代替支付 API。若目前只有学生个人身份，可以继续使用本项目模拟渠道，不必为求职演示专门注册经营主体。小微商户由具备权限的服务商按规定进件，不能假定适用于线上听书业务。

具备主体后：

1. 完成商户入驻，取得 `mchid`；按选择的产品准备并绑定 `appid`。PC 扫码、微信内 JSAPI、微信外 H5 的产品权限和配置不同。
2. 在账户中心的 API 安全页面设置 APIv3 密钥，申请商户 API 证书，保存私钥与对应序列号。
3. 按官方新接入方案准备微信支付公钥及公钥 ID；不要把商户私钥和微信支付公钥混淆。
4. 准备公网可访问的支付、退款通知地址；本机 `127.0.0.1` 与虚拟机私网地址不能直接接收官方通知。按部署地域和产品要求准备域名及 HTTPS。
5. 配置就绪后再进行真实下单、回调验签解密、金额/商户核对、退款、对账及权益授予验收；这些不能由填写配置文件替代。

官方参考：[申请材料](https://pay.wechatpay.cn/static/applyment_guide/applyment_detail_website.shtml)、[开发必要参数](https://pay.wechatpay.cn/doc/v3/merchant/4013070756)、[回调说明](https://pay.wechatpay.cn/doc/v3/merchant/4012791870)、[小微商户范围](https://pay.wechatpay.cn/doc/v2/partner/4014115330)。

## 阿里云数字人

原示例使用 LingMou 的云渲染会话接口。注册并实名阿里云账号后，先在万相数字人控制台体验、确认方案，再决定购买实例。

1. 创建本项目独立的云渲染对话项目，设置形象、声音及人设，测试后发布。
2. 保存项目配置 `ProjectId`，购买匹配的云渲染实时对话服务后，从订单详情取得 `InstanceId`。
3. 创建本项目 RAM 用户与所需授权，保存专属 `AccessKey ID` / `AccessKey Secret`。当前 LingMou Endpoint 为 `lingmou.cn-beijing.aliyuncs.com`。
4. 云渲染与端渲染是不同方案；云渲染会话不要求端渲染 SDK License。业务接入时还需验证会话关闭、并发上限、超时回收与每个用户的隔离。

官方参考：[云渲染对话创建](https://help.aliyun.com/zh/avatar/avatar-application/user-guide/cloud-rendering-full-stack-digital-human-real-time-conversation)、[CreateChatSession 参数](https://help.aliyun.com/zh/avatar/avatar-application/developer-reference/api-lingmou-2025-05-27-createchatsession)、[SDK 与 Endpoint](https://api.aliyun.com/api-tools/sdk/LingMou?version=2025-05-27)。
